# TE & NTE Web Portal — সম্পূর্ণ ডিপ্লয় গাইড (A to Z)

MS Techno Enterprise-এর এজেন্ট/ক্যাশবুক/HR ম্যানেজমেন্ট অ্যাপ।
**ডেটাবেজ হলো একটা Google Sheet**, আর ব্যাকএন্ড হলো Apps Script Web App।
অ্যাপের HTML/JS ফাইলগুলো যেকোনো হোস্টিংয়ে থাকতে পারে — মাঝে কোনো সার্ভার লাগে না।

# পর্ব ১ — Google Sheet + Apps Script (ব্যাকএন্ড বানানো)

## ধাপ ১: Sheet তৈরি করুন

1. [sheets.new](https://sheets.new) খুলুন — একটা নতুন খালি শিট হবে।
2. নাম দিন যেমন `TE & NTE Database`। (আর কিছু করতে হবে না — ট্যাব, হেডার,
   ডিফল্ট অ্যাডমিন সব কোড নিজেই বানাবে।)

## ধাপ ২: Apps Script-এ কোড বসান

1. Sheet-এ থেকে **Extensions → Apps Script**।
2. এডিটরে যে ডিফল্ট `function myFunction() {...}` আছে, পুরোটা মুছে ফেলুন।
3. এই ফোল্ডারের [`apps-script/Code.gs`](apps-script/Code.gs) খুলে **পুরো কোড**
   কপি করে এডিটরে পেস্ট করুন → **💾 Save** (Ctrl+S)।
4. উপরের `CONFIG` ব্লকে যা যা আছে:

   ```js
   var CONFIG = {
     SPREADSHEET_ID: '',                          // খালি রাখলে এই শিটটাই ব্যবহার হবে
     API_TOKEN: 'MSTE-17238487c260a9f644',        // js/config.js এর সাথে একই ✓
     DEFAULT_ADMIN_EMAIL: 'mstechnoenterprise@gmail.com',
     DEFAULT_ADMIN_PASSWORD: '694698',
     ...
   };
   ```

   `SPREADSHEET_ID` খালি রাখাই ভালো (স্ক্রিপ্ট যেই শিটে বাঁধা, সেটাই ব্যবহার হবে)।

## ধাপ ৩: `setup` ফাংশন একবার Run করুন

1. ফাইল লিস্টের পাশে ফাংশন-ড্রপডাউন থেকে **`setup`** বেছে **▶️ Run** দিন।
2. প্রথমবার Google অনুমতি চাইবে → **Review permissions → আপনার অ্যাকাউন্ট →
   Advanced → Go to ... (unsafe) → Allow**। (এটা আপনার নিজের স্ক্রিপ্ট, তাই
   "unsafe" লেখাটা স্বাভাবিক।)
3. Sheet-এ ফিরে গিয়ে **↻ রিলোড** দিন — দেখবেন ১৮টা ট্যাব তৈরি: `Users`,
   `Agents`, `CashBook`, `Expenses`, `Settings`, `ActivityLog`, `HREmployees` ইত্যাদি,
   আর `Users` ট্যাবে ডিফল্ট অ্যাডমিন অ্যাকাউন্ট।

## ধাপ ৪: Web App হিসেবে Deploy

1. Apps Script এডিটরে উপরে ডানে **Deploy → New deployment**।
2. বাঁ দিকে **⚙️ (Select type)** → **Web app**।
3. ঘরগুলো এভাবে দিন:
   - **Description**: `TE & NTE API`
   - **Execute as**: **Me (আপনার ইমেইল)**
   - **Who has access**: **Anyone**  ← "Anyone with Google account" **নয়**, শুধু `Anyone`
4. **Deploy** → হয়তো আবার অনুমতি চাইবে → Allow।

## ধাপ ৫: URL টা নিন

Deploy শেষে একটা ডায়ালগে **Web app URL** দেখাবে। পাশের কপি আইকনে চাপুন:

```
https://script.google.com/macros/s/AKfycb....../exec
```

পরে আবার দেখতে/কপি করতে: **Deploy → Manage deployments → Active → Web app URL**।

> ❌ `/dev` দিয়ে শেষ হওয়া URL নেবেন না — ওটা "Test deployment", শুধু আপনার
> নিজের লগইনে চলে। অ্যাপের জন্য **`/exec`** লাগবে।
>
> 🔁 পরে কোড বদলালে: **Deploy → Manage deployments → ✏️ Edit → Version:
> New version → Deploy**। URL একই থাকবে, তাই `config.js` আর বদলাতে হবে না।

# পর্ব ২ — অ্যাপে URL বসানো

## ধাপ ৬: `js/config.js` বদলান

[`js/config.js`](js/config.js) খুলে শুধু এই লাইনটা পূরণ করুন:

```js
const APP_CONFIG = {
  APPS_SCRIPT_URL: 'https://script.google.com/macros/s/AKfycb....../exec',  // ← এখানে পেস্ট
  API_TOKEN: 'MSTE-17238487c260a9f644',                                     // ← আগেই বসানো ✓
  ...
};
```

- `APPS_SCRIPT_URL` **খালি (`''`) রাখলে** অ্যাপ আগের মতোই চলে — সব ডেটা শুধু ওই
  ব্রাউজারে (Google Sheet কিছুই লাগবে না)। তাই ভুল হলে বা টেস্ট করতে চাইলে
  শুধু খালি করে দিলেই আগের অবস্থায় ফিরে যাবে।

## ধাপ ৭: শুধু URL-টা মিলিয়ে দেখুন (ঐচ্ছিক কিন্তু কাজে দেয়)

ব্রাউজারে এটা খুলুন (`আপনার_URL` আর টোকেন বসিয়ে):

```
https://script.google.com/macros/s/AKfycb....../exec?action=ping&token=MSTE-17238487c260a9f644
```

`{"ok":true,"action":"ping",...}` এলে URL + টোকেন দুটোই ঠিক।
`{"ok":false,"error":"unauthorized"}` এলে টোকেনের মিল নেই (Code.gs আর config.js
একসাথে মিলান)। আর লগইন/অনুমতি চাইলে ধাপ ৪-এর সেটিংস দেখুন।

# পর্ব ৩ — অ্যাপ হোস্ট করা (যেকোনো একটা বাছুন)

## ক) Netlify Drop — সবচেয়ে সহজ, ২ মিনিটে

1. [app.netlify.com/drop](https://app.netlify.com/drop) খুলুন (ফ্রি অ্যাকাউন্ট)।
2. এই ফোল্ডারটা (`TE & NTE Web`) ড্র্যাগ করে ওয়েবপেজে ছেড়ে দিন।
3. কয়েক সেকেন্ডেই একটা `https://xxxx.netlify.app` লিংক পাবেন — ওটাই আপনার অ্যাপ।
   পরে নাম বদলাতে: Site settings → Change site name।

## খ) GitHub Pages — ফ্রি, কোডও থাকবে সংরক্ষিত

1. github.com-এ নতুন রিপো (Public) বানান।
2. **Add file → Upload files** দিয়ে সব HTML/CSS/JS ফাইল (ও `js/`, `css/`
   ফোল্ডার) আপলোড করুন → Commit।
3. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**।
4. কয়েক মিনিট পর অ্যাপ পাবেন `https://ইউজারনেম.github.io/রিপো-নাম/` ঠিকানায়।

## গ) নিজের হোস্টিং / cPanel

1. cPanel → **File Manager** → `public_html` (বা সাব-ফোল্ডার, যেমন `tente`)।
2. সব ফাইল আপলোড করুন (zip আপলোড করে Extract করলেই সুবিধা)।
3. অ্যাপ চলবে `https://আপনার-ডোমেইন/tente/index.html`-এ।
4. **SSL (https) চালু করুন** — cPanel-এর Let's Encrypt/ AutoSSL।

## ঘ) নিজের পিসিতে টেস্ট (হোস্টিং ছাড়া)

ফোল্ডারে টার্মিনাল খুলে:

```bash
python -m http.server 8000        # অথবা:  npx serve .
```

তারপর ব্রাউজারে `http://localhost:8000` খুলুন। (শুধু টেস্টের জন্য — আসল ব্যবহারে
উপরের যেকোনো একটা হোস্টিং নিন।)

> 📌 কনফিগ কোথায় বদলাবেন: সবসময় **সোর্স ফাইলেই** `js/config.js` বদলে আপলোড
> করুন — ব্রাউজারে হাত দিয়ে বদলানো টেকসই নয়।

2. ডিফল্ট অ্যাডমিন দিয়ে লগইন:

   | ইমেইল | পাসওয়ার্ড |

   | `mstechnoenterprise@gmail.com` | `694698` |

3. **লগইনের পরপরই হেডারের ⚙️ Settings → প্রোফাইল থেকে পাসওয়ার্ড বদলে নিন।**

## ধাপ ৯: আগের ডেটা Sheet-এ তুলে দিন (একবারই)

আগে অ্যাপটা যদি কোনো কম্পিউটারে লোকাল মোডে চালাতেন (ডেটা ব্রাউজারে ছিল), তাহলে
সেই কম্পিউটারেই:

1. সিঙ্ক-ব্যাজে ক্লিক করুন → প্যানেলে কমলা লেখা আসবে:
   *"এই ব্রাউজারে আগের ডেটা আছে যা শিটে নেই (AGENTS, CASHBOOK …)"*
2. **“এই ডেটা শিটে আপলোড করুন”** বাটনে চাপুন → সব ডেটা একবারে Sheet-এ চলে যাবে
   ও পেজ রিলোড হবে।
3. Sheet খুলে দেখে নিন `Agents`, `CashBook` ট্যাবে ডেটা এসেছে কি না।

> অ্যাপ নিজেই বুঝে নেয় কখন এই দরকার — Sheet খালি অথচ ব্রাউজারে ডেটা থাকলে।
> Sheet-এ ডেটা থাকলে এই বাটন দেখাবে না।

# পর্ব ৫ — দৈনিক ব্যবহার

## সিঙ্ক ব্যাজ (স্ক্রিনের নিচে ডানে)

| ব্যাজ | মানে |
|---|---|
| 🟢 **Sheet synced** | সব লেখা Sheet-এ পৌঁছে গেছে |
| 🟡 **Saving…** | এখনই পাঠাচ্ছে |
| 🟡 **N pending** | কিছু লেখা অপেক্ষায় (কয়েক সেকেন্ডের ব্যাপার) |
| 🔴 **Offline • N pending** | নেট নেই — লেখাগুলো জমছে, নেট ফিরলেই নিজে থেকে যাবে |
| 🟠 **N conflicts** | একই রেকর্ডে দুজন লিখেছে — আপনাকে বেছে নিতে হবে (নিচে দেখুন) |

ব্যাজে ক্লিক করলে প্যানেল: কোন টেবিলে কত রেকর্ড, **এখনই সেভ করুন**,
**শিট থেকে রিফ্রেশ**, আর দরকার হলে মাইগ্রেশন বাটন।

## দুই ডিভাইস একসাথে একই রেকর্ড বদলালে

শিটে তার চেয়ে নতুন সংস্করণ থাকলে অ্যাপ আপনার লেখাটা **নিঃশব্দে মুছে দেয় না** —
ব্যাজ কমলা হয়ে `N conflicts` দেখায়, আর প্যানেলে কোন ঘর কার থেকে আসছে তা
দেখিয়ে দুইটা সিদ্ধান্ত দেয়: **শিটের সংস্করণ রাখুন** / **আমার সংস্করণ রাখুন**।
বিস্তারিত নিয়ম: [`apps-script/SETUP.md`](apps-script/SETUP.md) §৫.১।

## ব্যাকআপ ও রিস্টোর

হেডারের **⚙️ Settings → 2. ডাটা ব্যাকআপ ও রিস্টোর**:

- **Export Backup** → পুরো ডেটাবেজ একটা `.json` ফাইলে নামবে (মাসে একবার করা ভালো)
- **Restore** → ব্যাকআপ ফাইল থেকে ফিরিয়ে আনে; Sheet মোডে থাকলে ডেটা Sheet-এও যায়

## শিটে নিজে হাত দিয়ে ডেটা বদলানো

হয়, কিন্তু তিনটা নিয়ম:

1. **`id` কলাম বদলাবেন/মুছবেন না** — এটাই রেকর্ডের চাবি।
2. নতুন সারি হাতে যোগ করলে `id` খালি রাখুন — অ্যাপ নিজে বসিয়ে দেবে।
3. **`version`, `updatedAt`, `updatedBy` কলামে হাত দেবেন না** — এগুলো সার্ভার
   রাখে; বদলালে অ্যাপ মিথ্যা দ্বন্দ্ব দেখাতে পারে।

## ট্রাবলশুটিং

| লক্ষণ | কারণ ও সমাধান |
|---|---|
| 🔴 Offline, ডেটা আসছে না | `APPS_SCRIPT_URL` ভুল, বা deployment অ্যাক্সেস "Anyone" নয়, বা `/dev` URL ব্যবহার হয়েছে |
| `unauthorized` | `Code.gs` আর `js/config.js` এর টোকেন মিলছে না — দুটোতেই একই মান দিন |
| লগইন হচ্ছে না | Sheet-এর `Users` ট্যাবে ইমেইল/পাসওয়ার্ড দেখুন; নতুন অ্যাকাউন্টে `status` অবশ্যই `active` হতে হবে |
| পেজ খুলছে কিন্তু খালি | `file://` দিয়ে খুলেছেন — হোস্টিং/লোকাল সার্ভার দিয়ে খুলুন |
| অন্য ডিভাইসে পুরনো ডেটা নেই | ওই কম্পিউটারে একবার "এই ডেটা শিটে আপলোড করুন" চাপুন |
| শিটের বদল অ্যাপে দেখা যাচ্ছে না | ব্যাজের প্যানেলে **শিট থেকে রিফ্রেশ** চাপুন |
| কোড বদলেছি কিন্তু কিছু হচ্ছে না | নতুন **version** দিয়ে Deploy করেননি (পর্ব ৬ দেখুন) |
| পেজ খুলতে ১–৩ সেকেন্ড লাগে | স্বাভাবিক — প্রতি পেজ লোডে Sheet থেকে পুরো ডেটা আসে (তাই অফলাইনেও চলে) |

## নিরাপত্তা — যা মাথায় রাখবেন

- `API_TOKEN` আর `APPS_SCRIPT_URL` ক্লায়েন্ট কোডে থাকে (ব্রাউজারে View Source
  করলে দেখা যায়)। তাই **Sheet-টা কারো সাথে Share করবেন না** এবং `/exec` URL
  পাবলিকলি পোস্ট করবেন না — এটাই আসল সুরক্ষা।
- ইউজারের পাসওয়ার্ড শিটে **base64** আকারে থাকে (অ্যাপের পুরনো ফরম্যাট)।
  শিট সুরক্ষিত থাকলে এটা চলে; আরও শক্ত চাইলে পাসওয়ার্ড salt+hash করা যায়।
- অ্যাডমিন অ্যাকাউন্টের ডিফল্ট পাসওয়ার্ড (`694698`) **লগইনের সাথে সাথেই
  বদলে নিন**।
- নতুন ইউজার সাধারণত `user` রোল ও `pending` অবস্থায় তৈরি হয় — অ্যাডমিন
  অনুমোদন দিলেই সে ঢুকতে পারে।
